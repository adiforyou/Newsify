# News Summarizer AI Extension

## Overview

The **News Summarizer AI Extension** for Visual Studio Code allows users to fetch the latest news articles from various categories, including technology, sports, business, entertainment, health, and science. This extension provides a simple and efficient way to stay updated with current events directly within your code editor.

## Features

- **Category Selection**: Choose from multiple news categories to fetch relevant articles.
- **Latest News Fetching**: Get the latest headlines and summaries from trusted news sources.
- **User-Friendly Interface**: View articles in a dedicated webview panel, complete with titles, descriptions, and links to read more.
